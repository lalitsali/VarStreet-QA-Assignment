# VarStreet-QA-Assignment

What's covered

Part 1 — CRM Workflow Analysis (Tasks 1.1–1.6)

Lead-to-Deal lifecycle
Contact & Account management
Email & activity logging
Automation & workflow rules
Reporting & dashboards
Logical bugs identified (bug-report format)

Part 2 — Deep Product Understanding (Tasks 2.1–2.4)

Mental model of the CRM's data model
Feature impact assessment ("mandatory manager approval before Closed Won")
Cross-feature risk reasoning (top 3 highest-risk features to test)
CRM comparison from a QA perspective

Part 3 — Test Planning & Organisation (Tasks 3.1–3.4)

One-page test plan for the approval feature
Test suite structure for the Deal/Opportunity module (smoke, regression, edge case, integration)
4-hour pre-release prioritisation plan
Full Jira-style bug report for the most impactful issue found
How to view

 file are standard Microsoft Word (.docx) documents.

Open with Microsoft Word, LibreOffice Writer, Google Docs (upload/open), or any compatible editor.
No installation, build, or setup steps are required — these are static documents, not runnable code.
Notes & assumptions
The analysis is based on exploration of Zoho CRM and HubSpot CRM (trial/demo environments) cross-checked against each platform's current documented behaviour.
Where a specific detail (e.g. exact screen wording, log location) may vary by account configuration or product update, it is flagged inline in the report rather than stated as absolute fact.
Zoho CRM was used for the deeper single-CRM sections (Tasks 1.5, 2.1) and HubSpot CRM for others (Task 1.3), as the assignment allowed picking one CRM for depth in those sections.
